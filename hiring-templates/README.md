# Interview Scheduling Templates - Paperclip

This folder contains all hiring/interview scheduling templates for **Paperclip**, an early-stage company building spatial computing infrastructure in Rust.

## Contents

| File | Description |
|------|-------------|
| `00-cold-outreach-templates.md` | Cold outreach templates for founding engineer candidates (LinkedIn, HN, Discord) |
| `01-calendar-invites.md` | Calendar invite templates for each interview stage |
| `02-email-templates.md` | Email templates for confirmation, reminders, rejections, offers |
| `03-candidate-tracking.md` | Candidate tracking table, workflow diagram, and reporting template |
| `phone-screen-scorecard.md` | Scorecard for recruiter/HM phone screens |
| `technical-interview-scorecard.md` | Scorecard for engineering technical interviews |
| `final-round-scorecard.md` | Scorecard for leadership final round |

## Quick Reference

### Interview Stages
1. **Phone Screen** - 30 minutes (Recruiter/HM)
2. **Technical** - 60-90 minutes (Engineering)
3. **Final Round** - 45-60 minutes (Leadership)

### Standard TAT Targets
| Stage | Target Time |
|-------|-------------|
| Phone → Technical | 3-5 days |
| Technical → Final | 5-7 days |
| Final → Decision | 3-5 days |
| Decision → Offer Sent | 1 day |

## Usage

1. Copy the appropriate template for each candidate interaction
2. Customize with candidate-specific details
3. Log all activity in the candidate tracking system
4. Complete scorecards within 24 hours of each interview
5. Review pipeline weekly using the report template

## Customization Notes

- Replace all `[bracketed placeholders]` with actual values
- Adjust email tone based on company culture (we're technical/engineering-focused)
- Modify scorecard criteria to match role requirements
- Add Paperclip branding/logos to email templates as needed
