## API Routes Added

### Faction Routes (`/api/v1/factions`)
- `GET /` - List factions for a world (requires world_id param)
- `GET /types` - List available faction types
- `GET /:id` - Get faction details (requires world_id param)
- `GET /:id/relations` - Get diplomatic relations
- `GET /:id/turn` - Get faction turn state
- `POST /:id/turn/advance` - Advance faction turn
- `POST /:id/assets` - Add asset to faction

### World Turn Routes (`/api/v1/worlds/:id/turn`)
- `GET /turn` - Get turn state for all factions
- `POST /turn/action` - Execute turn actions
