## Bugs Found

### BUG-161-01: API Enum Case Mismatch
- **Severity:** Medium
- **Component:** Backend API (Rust)
- **Description:** The `parameters.size` field expects PascalCase enum values (`"Medium"`, `"Small"`, `"Large"`) but the frontend or test fixtures send lowercase (`"medium"`).
- **Impact:** Creating worlds via API returns 422 Unprocessable Entity instead of successful creation.
- **Repro Steps:**
  1. Send POST to `/api/worlds` with `{"name": "Test", "parameters": {"size": "medium"}}`
  2. Observe 422 response instead of 201
- **Fix:** Either normalize case in frontend or accept lowercase in backend deserialization.
