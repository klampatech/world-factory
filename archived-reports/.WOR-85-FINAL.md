## API Endpoints Added

### Faction Routes (`/api/v1/factions`)
- GET `/` - List factions (requires world_id param)
- GET `/types` - List faction types
- GET `/:id` - Get faction details
- GET `/:id/relations` - Get diplomatic relations
- GET `/:id/turn` - Get turn state
- POST `/:id/turn/advance` - Advance turn
- POST `/:id/assets` - Add asset

### World Turn Routes (`/api/v1/worlds/:id`)
- GET `/turn` - Get all faction turn states
- POST `/turn/action` - Execute turn action
- GET `/factions` - Get all factions
